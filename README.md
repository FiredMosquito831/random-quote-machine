## What this project is

A self-contained single-page app written in vanilla ES6+ against the DOM API, built to satisfy
every user story freeCodeCamp publishes for this project. The page embeds freeCodeCamp's
`testable-projects-fcc` bundle so the project's own user stories can be run in the browser.

- **Curriculum:** freeCodeCamp Front End Development Libraries (v8, archived)
- **Project type:** Certification project
- **Tech stack:** JavaScript, HTML5, CSS3
- **Challenge page:** <https://www.freecodecamp.org/learn/front-end-development-libraries/front-end-development-libraries-projects/build-a-random-quote-machine>
- **Live demo:** <https://FiredMosquito831.github.io/random-quote-machine/>

## Project files

- `index.html` — the whole app (markup, styles and script inline, no build step)

## How to run

Open `index.html` in any modern browser, or serve the folder:

```bash
npx serve .
```

The freeCodeCamp test suite appears as a small fold-out panel in the page corner once the
page is open in a browser.

## User stories

- I can see a wrapper element with a corresponding id="quote-box".
- Within #quote-box, I can see an element with id="text".
- Within #quote-box, I can see an element with id="author".
- Within #quote-box, I can see a clickable element with id="new-quote".
- Within #quote-box, I can see a clickable <a> element with id="tweet-quote".
- On first load, a random quote is displayed in #text and its author in #author.
- Clicking #new-quote fetches a new quote and author.
- The #tweet-quote link includes the twitter.com/intent/tweet path.
- The #quote-box wrapper is horizontally centered.

All of these pass when the freeCodeCamp test suite is run against this page.
